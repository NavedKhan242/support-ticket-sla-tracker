# Support Ticket & SLA Tracker

Bun + TypeScript + GraphQL Yoga + PostgreSQL + Prisma + React

## Quick Start

```bash
docker compose up -d
bun install
bun run db:generate
bun run db:migrate
bun run db:seed
bun run dev
```

Frontend:
```bash
cd frontend
bun install
bun run dev
```
